Engineering Architecture & Concurrency Defense

Key mechanisms implemented for race condition prevention & ACID compliance

1. Atomic Conditional Updates: UPDATE parking_slots SET status = 'OCCUPIED' WHERE slot_id = ? AND status = 'AVAILABLE' Guarantees SQLite atomicity. If two threads compete for the same slot, exactly one thread sees rowcount == 1; all competing threads see rowcount == 0 and are safely rejected.
2. Database Partial Unique Constraint: CREATE UNIQUE INDEX idx_active_slot_booking ON bookings(slot_id) WHERE status = 'ACTIVE' Hard schema-level barrier preventing duplicate concurrent active allocations for the same slot.
3. Immediate Write Locks & WAL Mode: Transactions use BEGIN IMMEDIATE with PRAGMA journal_mode = WAL to prevent lock escalation deadlocks and ensure non-blocking concurrent reads.
